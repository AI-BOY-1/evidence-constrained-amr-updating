# Evidence-Constrained AMR Updating Controller

Portable research code for the evidence-constrained antimicrobial-resistance
(AMR) updating controller, accompanying the retrospective study **“Evidence-
constrained updating of antimicrobial-resistance prediction under limited
testing.”**

**Author:** Xingran Guo

This repository is an executable code handoff, not a data release or a claim of
clinical readiness. It contains a configurable implementation of the controller,
metrics and audit replay, a synthetic smoke-test demo, schemas, and immutable
snapshots of the code bound to the reported ANI-screened analysis.

## What is included

- `src/ncs_amr/`: portable implementation of the five expert rules, likelihood
  evidence updates, approximate disagreement query score, metrics, role checks
  and audit acquisition.
- `scripts/run_demo.py`: deterministic synthetic example with masked query,
  audit and evaluation labels. Its output is a software smoke test, not a
  scientific result.
- `scripts/run_controller.py`: run the controller on a user-supplied JSONL
  cohort after you have verified the data licence, labels and split design.
- `tests/`: unit tests for label masking, role separation, weight updates,
  query-score properties, metrics and label-blind audit ordering.
- `historical_frozen/source_snapshots/`: exact source snapshots used in the
  reported analyses. They preserve historical absolute paths and dependencies
  for provenance; they are not the portable entry point.
- `docs/`: data schema, reproducibility steps and scientific scope.

Generated predictions, FASTA assemblies, AST records, ResFinder assets, MALDI
weights, photographs and manuscript figures are excluded.
They must be obtained and licensed independently. Do not commit patient-level or
restricted records.

## Quick start

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/run_demo.py --out demo_output
python -m unittest discover -s tests -v
```

The demo writes only synthetic JSON and a manifest. The expected scientific
results in the paper are not regenerated by this command.

## Running user data

`run_controller.py` consumes JSONL with one object per record:

```json
{"sample":"s1","component":"component_a","year":2021,
 "standards":"EUCAST","features":["sketch31::123"],"label":1,
 "role":"source"}
```

Provide four non-overlapping roles (`source`, `query_pool`, `audit`,
`evaluation`) and use `--query-budget` values supported by the query pool. The
script masks audit/evaluation labels before selection. It refuses overlapping
sample or component identities and refuses query labels outside the query pool.
Role assignment is supplied by the caller so that a study can bind it to its
own pre-specified partition protocol.

## Reproducibility and scientific boundaries

The controller is an exploratory machine-learning procedure. Evidence weights
are weights over predictive rules, not biological causes. The diagnostic query
score minimizes a fixed predictive-disagreement surrogate, not clinical risk or
target Brier loss. Approximate ANI components are not SNP phylogeny and do not
prove patient or laboratory independence. A single permutation is not a null
distribution. See `docs/SCIENTIFIC_SCOPE.md` before using the code.

The historical snapshots are hash-bound to the source manifest used in the
manuscript package. If you modify any method, create a new versioned result
directory and rerun affected analyses; never mix results from different code
hashes.

## Full study scripts

`research/` contains the curated study runners, analyses, validators and figure scripts, including their local import dependencies. They use `NCS_DATA_ROOT` for data paths. Read [full reproduction instructions](docs/REPRODUCE_STUDY.md) and `PORTABILITY_MANIFEST.json` for changes and required assets. The original five core ANI source hashes are preserved separately. Full experiments require external assets and were not run for packaging.

Portable core numerical bodies are extracted unchanged from the historical source; the wrapper adds role/budget/reveal validation. It supports all four formal E. coli strategies. `standard` metadata is mapped to the original context feature name `country` for numerical parity; it does not imply a geographic variable.

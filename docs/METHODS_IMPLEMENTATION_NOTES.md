# Methods implementation notes for manuscript writing

These notes describe the current evidence-bound implementation, not a new experiment. Read the frozen protocols in methods/ and distinguish original sketch experiments, later ANI-screened experiments and post-result analyses. Do not describe all stages as preregistered or blind. Historical COUNTEREXAMPLE_REPAIR_README.md describes an earlier heuristic and is not the Methods source for the present controller.

## 1. What the AI algorithm actually does

The genomic controller is a machine-learning procedure combining logistic prediction experts, predictive-evidence weight updates, approximate information acquisition and action selection. It is not a newly invented deep neural architecture. The supplementary MALDI reexecution uses a published CNN; the independent photo experiment uses standard Ridge and ExtraTrees models. These are separate unpaired tasks, not one multimodal model.

The five candidate rules are frozen_gene, frozen_context, updated_gene, updated_context and intercept_update. A gene-only logistic model uses binary input-token presence. For E. coli these are either k31 scaled5000 sketch hashes or homolog-candidate tokens. The context model adds source-reported standards and three-year collection bins. The inherited Record.country field holds standards in the E. coli runners, not geographic country. Ambiguous collection years are set to 0. Do not infer geographic effects from this variable.

ProbabilityModel uses sparse DictVectorizer, LogisticRegression(C=1, solver='liblinear', max_iter=1500, random_state=seed). If a fitted subset has one class, the implementation returns its constant class probability; this is not an extra learned model. Updated gene/context rules refit source plus all labels queried so far. The intercept rule adds a scalar a to frozen-gene logits, fitting queried labels with sum(logaddexp(0,z)-y*z) + a*a/2, using bounded optimization a in [-6,6]. It does not fit audit or evaluation labels.

Weights start uniformly across the five rules. For each batch, predictions are cached before revealing labels. Weights are multiplied by the Bernoulli likelihood of those labels and normalized in log space; probabilities are clipped to [1e-6,1-1e-6]. They are evidence weights over predictive rules, not a posterior over identified biological mechanisms or causes.

Let p_j(x) be candidate probabilities on the remaining query pool and A_jk = mean_x (p_j(x)-p_k(x))^2. The diagnostic action is argmin_k (w^T A)_k. For a potential label at x, compute its predictive marginal and the two likelihood-updated weight vectors w^(1), w^(0). The query score is max(0, min_k(w^T A)_k - [m(x) min_k(w^(1)^T A)_k + (1-m(x)) min_k(w^(0)^T A)_k]). This freezes current candidate probabilities and approximates single-label reduction in minimum disagreement. It is not direct minimization of clinical harm, target Brier or asymmetric clinical risk; no such utility weights were fitted.

Queries are selected in static batches of five, with seed-based tie jitter up to 1e-12, then revealed and incorporated. The query pool is exhausted only up to the largest feasible fixed budget. Audit/evaluation labels are masked as -1 in the trajectory interface. Audit labels do not choose its original queries, training updates or actions.

The four formal E. coli strategies are decision_diagnostic, random_gene, uncertainty_gene and random_tree. random_gene uses random queries and the refitted gene model; uncertainty_gene uses its entropy and that model; random_tree uses the same random-query policy and ExtraTreesClassifier(n_estimators=200, min_samples_leaf=2, random_state=seed, n_jobs=2). Do not describe these generic controls as exact published active-learning algorithm replications.

## 2. Cohort, input and partition versions

3,516 FASTA files passed the stated loose integrity audit, with final missing count 0; this is not species-purity, contamination or complete-genome certification. The public sequence inventory is distinct from each drug's eligible labelled cohort. Original labels are retained. Discordant labels for the same sequence ID, exact normalized sequence or shared BioSample are excluded in a fixed order with denominators preserved. A related component may legitimately include both AST labels.

Original full sequence experiments used scaled1000 Jaccard edges at 0.99 and 0.95, shared BioSample and exact sequence groups; model features were downsampled to k31 scaled5000. Fig. 2 and the frozen-query ablation refer to these original sketch components. They must never be relabelled ANI isolation.

Later full-cohort approximate skani screening used an approximate cutoff 0.99 for computational feasibility; the earlier 0.80 attempt was stopped before per-query results. Screening can miss pairs. For each retained pair, the component code conservatively unions genomes if EITHER available direction passes identity >=0.99 (or sensitivity 0.999) and min(query_fraction, reference_fraction) >=0.80. It does not require both directions independently to pass. Shared BioSample and exact normalized sequence groups also connect genomes. Connected components can contain transitive links; they are not pairwise SNP trees, proof of clonality, or patient/laboratory identifiers.

For component c and seed s, int(sha256(f'{s}:{c}').hexdigest()[:8],16) modulo 10 assigns roles: 0-3 source, 4-6 query, 7 audit, 8-9 evaluation. These are hash buckets, not guaranteed exact percentages. Seeds are 7,17,27,37,47; queried budgets are 0,10,25,50 when feasible. Both inputs use identical new partitions. Configurations lacking source classes, sufficient query/evaluation support or source features are kept as skips. The ANI run produced 680 trajectories and 2,720 metric rows; 10 input/partition skips correspond to 40 strategy trajectories, not ten missing metric rows.

Homolog input comes from a pinned ResFinder 2.6.0 snapshot (eecf0aa20759), BLASTn 2.17.0+, identity >=90%, single-HSP reference span >=80%, E-value <=1e-10. Tokens use reference names before the underscore. These are acquired-gene homology candidates, not full official AMR annotation, validated allele function, mutation calling or mechanism confirmation.

The original quality sensitivity filters only saved evaluation predictions: total assembly length 3-7 Mb, N50 >=10,000 bp, ambiguous-base fraction <=1%. It does not retrain, remove original main results or establish training contamination control. Do not assume this original sensitivity was newly run for every downstream analysis.

## 3. Metrics, ablation and audit studies

E. coli resistant label is 1; p >=0.5 is a resistant call. False susceptibility (FS) is recorded R called S; false resistance (FR) is recorded S called R. Report counts and exact R/S denominators. FS/R is undefined at R=0, not zero. Separate it from resistant-among-predicted-sensitive. Brier is mean((p-y)^2); lower is better. Undefined one-class AUROC is retained as unavailable. MALDI has its own threshold p >0.5; do not silently impose the E. coli tie convention.

The frozen-query ablation re-fits the same logistic model on saved paths. R is random-path refitting, G is diagnostic-path refitting, and D is the original diagnostic output. Brier(D)-Brier(R) = [Brier(G)-Brier(R)] + [Brier(D)-Brier(G)] on exactly the same evaluation identities. This is descriptive algebra, not causal mediation or an independent policy trial.

The ANI dynamics analysis includes 4,080 forward-budget comparisons, of which 2,040 are adjacent. The 1,360 gate replays and their rollback subsets must be distinguished from the later acquisition experiment. Gate result counts in the writing brief refer to rollbacks relative to consuming the same budget and updating; do not describe them as the performance of all accepted updates.

The acquisition study reuses all 680 frozen ANI trajectories without new training. Fixed factors: query budget 10/25/50; purchased audit labels 5/10/25/50; random, predicted_R and component_coverage acquisitions; retain, update, audit_loss, audit_direction and component_direction rules. Acquisition sees only audit identities, component IDs and frozen p_b0, never true labels before purchase or evaluation outcomes. SHA256-derived order fixes random selection; predicted_R ranks p_b0 descending; component_coverage round-robins components. Component coverage is not proven patient/laboratory/source coverage.

retain returns budget-zero probabilities; update returns current-budget probabilities. audit_loss updates only for strictly lower sampled-audit Brier. audit_direction also requires audit R>0 and no FS increase. component_direction uses equally weighted component Brier and R-component FS rate with the same strict-loss/nonincrease criteria. Ties retain. Direction rules with no audit R remain explicitly infeasible with retention, not successful safety checks. Both queried and selected audit labels are charged to every action, including retain/rejection. Source labels are shared previously paid costs; evaluation labels are offline scoring references, not free deployed evidence. See the protocol for precise matched conditions and oracle boundaries.

All partitions, configurations and drug summaries remain descriptive observations sharing a retrospective cohort. Do not fabricate p-values, independent sample counts or confidence intervals. Report an interval only where an attached source actually supplies it with its specified resampling unit; do not transfer original component bootstrap intervals to new analyses. Each seed's single permutation control is not a statistical null distribution.

## 4. Separate image and spectral tasks

CombiANT: 279 matched photos from 98 plates; five GroupKFold partitions by plate. Inputs are centered square RGB crops resized to 32x32 plus 22 global features. Ridge alpha=100 and ExtraTreesRegressor with 128 trees, min_samples_leaf=3, max_features=1.0, seed=7, n_jobs=1; half-resolution Ridge is a sensitivity. Complete-case fitting handles one missing A target; valid remaining distance outputs are retained. Twenty-five fits, 294 metrics and 2,040 review-simulation records are not patients or new wet experiments. The published software distances are comparison outputs, not input features. Review replaces selected predictions with available human reference values and is a simulation, not an intervention. Keep published photo attribution and licensing.

MSDeepAMR: three DRIAMS-B tasks, ten local stratified 80/20 splits, four strategies; 120 configurations, 12 summaries, 90 same-test comparisons. The published source weights are reused. Target adaptation uses Adam 1e-7, 10 epochs, batch32 following the paper text; local fitting uses Adam1e-4, up to100 epochs, batch10, training-tail10% validation with early stopping/learning-rate reduction. Frozen-feature fitting reinitializes the last four Dense layers; do not describe it as preserving the source head. The compatible TensorFlow2.16.1/tf-keras2.16 environment and local splits differ from the original setup. This is B-subset reexecution, not exact full-paper C/D reproduction. Each target-test R is only 9/4/4. No original project controller was tested on spectra.
